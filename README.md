# Real-Time Order Processing System

## Project Overview

This project is a real-time e-commerce order processing system built using event-driven architecture. It processes orders, payments, and shipments in real-time using Apache Kafka, Apache Flink, and Spring Boot, ensuring scalability, resilience, and real-time analytics.

## Tech Stack

### Data Ingestion & Streaming:
* Apache Kafka (Event Broker)
* Spring Boot (Microservices Producers)

### Real-Time Processing:
* Apache Flink (Streaming Data Processing)

### Storage Layer:
* PostgreSQL (Structured Data)
* MongoDB (Semi-Structured Data)
* Redis (Caching)

### API & Microservices:
* Spring Boot (REST APIs for querying data)

### Monitoring & Deployment:
* Prometheus & Grafana (System Monitoring & Visualization)
* Docker & Kubernetes (Containerized Deployment)
